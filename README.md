# Laboratorio Web

A collection of early front-end projects and exercises from the Web ITAM Laboratory (WIL) at Instituto Tecnológico Autónomo de México. The examples cover page structure, layout, JavaScript, and browser requests.

## Where to start

- [Web portfolio](Portafolio_P%C3%A1ginas_Web/) — A collection of web pages built during the lab.
- [Flexbox challenge](Reto_FlexBox_Random/) and [box model exercises](Ejercicios_Box_Model/) — Practice with CSS layout and spacing.
- [JavaScript exercises](Ejercicios_JavaScript/) — Small examples for exploring browser-side JavaScript.
- [AJAX](AJAX/) and [Requests](Requests/) — Exercises that explore fetching data from the browser.

## Run an example locally

Clone or download the repository and choose a project folder. Open its HTML entry file in a browser. For examples that need to be served over HTTP, run the following from the repository root and navigate to the example folder in your browser.

```sh
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000). These are historical lab exercises, so examples that call third-party endpoints may depend on services that have changed.
